灵动岛
======

把压缩包整个解压到一个文件夹，双击 DynamicIsland.exe 运行。不需要安装 .NET。
请让 DynamicIsland.exe 和 runtimes 文件夹留在一起，不要只拷走这一个 exe。
第一次打开会多等几秒，程序在把自己解出来。

Windows 可能会弹出“Windows 已保护你的电脑”。
这是因为程序没有购买代码签名证书。点“更多信息”，再点“仍要运行”。

岛默认停在屏幕顶部正中。可以拖动，松手后吸到这块屏幕工作区的
上下左右中点或四个角，并躲开任务栏。左右两侧会变成竖胶囊。
鼠标放上去，或者点一下，它会展开。鼠标离开后，大约半秒收回去。
这块屏幕进入全屏时，岛会收成一颗小点，结束后恢复。

右下角托盘（时钟旁边）有一个小图标：
- 左键：把岛展开几秒
- 右键：菜单
    显示器        换到另一块屏幕
    开机时启动    勾上之后，下次登录会等约 12 秒再打开
    隐身          收成小点。音量、电池和通知仍会短暂冒出来
    在岛上显示通知中心
                  默认关。先允许本程序读取通知，再在微信、
                  QQ 或其他软件里打开系统通知。只有进了
                  Windows 通知中心的消息才会出现在岛上。
    翻译剪贴板    翻译你刚复制的文字。点之前不会把文字发出去
    翻译结果      再打开最近一条译文。没有译文时是灰的
    摄像头画中画  默认关。收起或关掉就放开摄像头
    打开秒表 / 开始 25 分钟专注
    发送一条测试通知
    打开日志
    退出          关掉程序。岛本身没有关闭按钮。

设置里可以打开「实时翻译」：把系统正在播放的外语译成中文，显示在岛上。说话大约 0.26 秒后就会开始出字并同时翻译，不必等这句说完，识别切片约每 0.26 秒更新当前句；翻译则单请求合并最新稿，完成后至少间隔约 0.8 秒，不再每次出字都取消请求；停顿约 0.64 秒后再仔细识别一次。翻译接口会因此更频繁地被调用，偶尔可能因网络或识别排队而慢一拍。字幕岛更紧凑，仍能看见最近几句；新字幕或同一句变长时，只要你还在底部附近就会自动滚到最新一行，滑上去读历史时不会被拽走。本次打开大约能记住 40 句，并标上从开始收听算起的时间。默认用公开翻译接口，也可以在设置的「翻译」分组里改成自己的模型。有可用的显卡时会走 Vulkan 加速，没有则用处理器；识别会参考上一句，整句也可以说得稍长一些。第一次会下载约 181 MB 的识别模型（优先走国内镜像，卡住会自动换源），之后缓存在本机，以前较小的模型在新模型就绪后会被清掉。关闭后不再听声音。设置的「外观」里可以调整岛的大小，也可以把岛换成更通透的液态玻璃：中间几乎透明，边缘月牙和高光贴合岛的跑道形轮廓，反射薄边约 9 DIP，展开不再过度变粗；玻璃外框、内沿、折射和内容裁剪共用圆弧轮廓，圆角外真实背景也会捕获，不再硬拼矩形四带，各段边沿各自反映附近背景，每像素做 5 个局部双线性采样，默认不做 RGB 色散，避免彩虹串色，不会在中间单独画出一块椭圆；播放键等控制键也是通透玻璃。会尽量用显卡加速折射和高光，显卡不可用时自动退回处理器。拖动、展开和收起时持续按当前形状提交液体和高光；捕获与渲染在后台各最多一个任务，显卡使用三槽非阻塞读回，忙时用最近完成帧，不积压也不让输入等 GPU。按 60fps 的 16.67ms 预算优化，尚未在实际 Windows / 外置显卡证实稳定 60fps。每约 10 秒日志只汇总新帧完成、UI 提交、捕获率、耗时 p95 和跳过数，不含屏幕内容；UI 提交率不是实际显示帧率。指针 1:1 跟上，并可甩出、松手有 Q 弹，文字仍保持清晰。这些外观选项会记住，实时翻译开关不会。如果提示识别组件加载失败，请安装微软 Visual C++ 可再发行程序包（x64）后再试。蓝牙耳机和扬声器都可以，声音不必从扬声器出来，程序捕获的是当前正在播放的那台设备。如果提示无法捕获系统声音，请先确认有声音正在播放，并在「设置 → 隐私和安全性 → 麦克风」里允许桌面应用使用麦克风，改完权限后请彻底退出程序再打开；有的游戏会独占音频设备，这时也听不到。

译文出来以后，鼠标移开不会马上收起。可以选中，用 Ctrl+C、右键「复制」或「复制」按钮复制。
点「关闭」会清掉这条译文。已经复制过再把鼠标移开，也会丢掉。
竖着停靠时，正在播放的封面在格子里居中，多出来的从中间裁掉。
这块屏上的无边框全屏（比如播放器铺满屏幕）也会把岛收成小点。别的屏幕上的全屏不会。
有多条正在播放的会话时，展开后可以用封面上的箭头或滚轮切换，按钮只控制眼前这一条。

开机启动写在当前用户的注册表里，不需要管理员：
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
名字是 DynamicIsland。

日志和设置在：
%AppData%\DynamicIsland\
    log.txt
    settings.json

识别模型（仅在打开过实时翻译后出现）在：
%LocalAppData%\DynamicIsland\models\

通知中心要做两件事，否则岛上看不到微信或 QQ：
1. 设置 → 隐私和安全性 → 通知，允许「灵动岛」读取通知。
   Windows 10 是：设置 → 隐私 → 通知。
2. 在微信、QQ 或其他软件自己的设置里打开系统通知，并在
   Windows「设置 → 系统 → 通知」里允许那个软件。
消息必须真正进了通知中心。程序不读取这些软件自己的窗口。

需要 Windows 10 版本 2004（内部版本 19041）或更新的系统，以及 Windows 11。
详细说明见项目里的 README.md。

设置后台新版
左侧固定分类：外观与停靠（默认）、翻译、通知、隐身与应用、快捷工具。右侧仅滚动当前分类。原有功能和设置值保留；可直接选择显示器和八向停靠。大小/皮肤/方向/通知/隐身等即时生效；API 地址、模型、密钥和接口类型需要点「保存接口配置」，只校验本地格式，不主动测试联网。切页不丢草稿，关闭有未保存接口修改时会询问保存/放弃/继续。密钥仍使用原有本地存储方式，不写日志。支持 Tab、方向键/空格、滚轮及右下角调整窗口大小；实际 Windows 桌面外观、键盘与多屏 DPI 仍需实测。

连续翻译修复与翻译源（t57）
字幕现在以分段ID更新；空终稿/新段不会覆盖上一整段，明显坍缩的短稿保留旧识别，正常纠错仍可改短。翻译请求不再每0.26秒取消；始终只有一个进行中的实时请求、最多40个合并待译稿，失败保留原文/已有译文。40条历史只淘汰最旧项，回看时按字幕身份保持位置。关闭立即取消并停止捕获信号，后台等识别/请求/STA/GPU安全结束后释放；还未在真实Windows桌面复现或确认用户的native崩溃。
设置→翻译可明确保存选择MyMemory（匿名5000字符/日）、OpenAI兼容、LibreTranslate自建（免费软件但运行成本自理，URL必填、Key可选）、Azure F0（200万字符/月，需自己免费层Key和资源区域）、DeepL（新Developer总100万字符一次性，旧Free每月50万；需自己Key）。Azure账号通常需绑卡验证，程序不会开户；有Key不代表免费，付费计划可能计费。无自动切源、无多源广播、切源不清历史。默认MyMemory选择不被修改。官方托管LibreTranslate实测不带Key返回400，不能把它当免费公共源。外部额度与网络/地区不保证；新Key仍只保存在现有本地设置文件，不记日志。
